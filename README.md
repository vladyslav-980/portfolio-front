# Portfolio Frontend

Bilingual developer portfolio built with Next.js, TypeScript and Tailwind CSS.

## Local start

1. Install Node.js 22 or newer.
2. Copy `.env.example` to `.env.local`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

The backend should run on `http://localhost:4000`. For Vercel, set `NEXT_PUBLIC_API_URL` to the public Render backend URL.

The Hero photo currently uses the public GitHub profile image. It can later be replaced with a dedicated portrait in `public/`.
